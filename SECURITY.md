# Security

## Reporting a vulnerability

Do not report suspected security issues through a public GitHub issue.

Report potential vulnerabilities through the [AWS vulnerability reporting page](https://aws.amazon.com/security/vulnerability-reporting/). Include the repository name, affected file or resource, reproduction details and potential impact when possible.

## Deployment responsibility

This repository contains non-production sample code. Review and adapt its IAM permissions, networking, encryption, logging, retention, monitoring, sharing and deletion behavior before use. See [THREAT_MODEL.md](THREAT_MODEL.md) for known trust boundaries and residual risks.
